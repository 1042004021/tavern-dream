# PRD - v0.4 交互增强与生图模型

## 1. 背景

v0.3.1 已经能「对话 + 自动配图」，但日常使用中暴露出三个体验缺口，以及一个模型能力缺口：

| 缺口 | 现象 |
|---|---|
| 正文拿不走 | 模型回复想存下来只能截图，长按没反应 |
| 图看不清 | 配图在气泡里只有小图，点了没反应 |
| 只有深色 | 白天户外看不清楚 |
| 复杂提示词不出好图 | SD1.5 的 CLIP 硬上限 77 token，提示词一长就被截断；中文直接不认 |

## 2. 需求范围

### 2.1 对话内容可复制

- 长按任意文本气泡 → 内容写入系统剪贴板，界面提示「已复制」。
- 图片气泡长按等同点击（无文本可复制，不误触）。

### 2.2 图片可放大查看

- 点击对话中的图片 → 全屏查看。
- 支持双指缩放（1~6 倍）与拖动平移。
- 点击空白处或右上角关闭按钮退出。

### 2.3 浅色 / 深色主题

- 三种模式：跟随系统、浅色、深色。
- 设置页「外观」卡片切换，立即生效，不需要点保存。
- 状态栏 / 导航栏图标颜色随主题变化。

### 2.4 生图模型升级与提示词优化

- 新增 **SD 2.1** 生图模型作为可选项（约 1.3GB，原生 768×768，v-prediction）。
- 提示词链路优化：
  - 含中文时先由对话模型改写成英文 tag（CLIP 不认中文）。
  - 按 77 token 的安全线截断（SD1.5 的硬上限），去重复标签。
  - 自动补质量词。
- 超分策略调整：768 级出图不再 4x 超分（否则会到 3072×2304，无意义且吃内存）。

## 3. 非目标

- 不接入 SDXL：实测单进程 PSS 5.5GB，12GB 机型触发 LMK 并重启，见 Task05 第 9.3 节。
- 不做图片编辑 / 局部重绘。
- 不做消息搜索与导出（后续版本再议）。

## 4. 验收标准

| 序号 | 验收项 |
|---|---|
| 1 | 长按文本气泡提示「已复制」，剪贴板内容与气泡一致 |
| 2 | 点图片进入全屏，双指放大到 6 倍仍可拖动，点空白关闭 |
| 3 | 设置里切浅色/深色立即生效，重启后保持 |
| 4 | 生图模型列表出现「SD 2.1（提示词理解更好）」，可下载可用 |
| 5 | 中文提示词（如「画一张她在吧台调酒」）能生成语义相符的画面 |
| 6 | 长提示词不再出现「后半句完全没体现」的情况 |
