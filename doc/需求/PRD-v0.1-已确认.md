## 2. 需求概述

### 2.1 背景

SillyTavern（酒馆）是 Node 服务 + 浏览器 UI，手机上需要 Termux/容器方案，布局为桌面形态。目标是做一个 Kotlin 原生 App：只保留「导入角色卡 → 和 AI 对话」这条主线，并把 local-dream 的端侧 Stable Diffusion 内核直接内置于同一 App，实现聊天中按需出图。

### 2.2 目标

1. 一个 APK 装完即可用（除模型需下载）。
2. 三个页面满足全部操作，无侧边栏、无多用户、无扩展商店。
3. 兼容酒馆角色卡（PNG V2/V3、JSON、CharX）。
4. 对话走 OpenAI 兼容接口，流式输出。
5. 生图在进程内调用本地 SD 后端，不依赖第二个 App。

### 2.3 范围

**做**：角色卡导入/删除、单角色会话、流式对话、聊天持久化、清空会话、本地生图、模型下载与管理、API 配置。
**不做（v0.1）**：世界书、群聊、TTS、翻译、正则脚本、向量记忆、扩展、导入导出聊天记录、多用户。

## 3. 功能需求

| 编号 | 功能 | 验收标准 |
|---|---|---|
| F1 | 导入角色卡 | 选择 PNG/JSON/CharX 后，列表出现该角色，头像与名称正确；无法识别时给出提示 |
| F2 | 角色列表 | 双列卡片展示；长按可删除（含聊天记录） |
| F3 | 对话 | 首次进入展示 first_mes；发送后逐字流式显示；异常有提示且不丢已输入内容 |
| F4 | 持久化 | 退出重进后消息仍在；按角色隔离 |
| F5 | 配置 | 可填 BaseURL / API Key / 模型名 / 用户名 / 温度 |
| F6 | 本地生图 | 后端自动启动；显示进度；生成图以图片消息插入会话；可配置提示词/负面提示词 |
| F7 | 模型管理 | 可下载 SD 模型（含进度、解压状态），可换下载源（HF / hf-mirror） |
| F8 | 引擎管理 | 可手动启动/停止生图引擎，并显示状态 |

## 4. 非功能需求

- 仅 arm64-v8a，minSdk 28。
- 生图引擎以前台服务运行，需通知与保活。
- 不采集任何数据，全部本地存储。
- 许可证：local-dream 为 CC BY-NC 4.0，仅限非商业自用；酒馆仅作功能与格式参考。
