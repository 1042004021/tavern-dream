## 2. 需求概述

### 2.1 背景

v0.2 已经跑通「本地对话 + 本地生图」，但实际用下来有几个明显不顺手的地方：生图要点按钮开弹窗、设置占着一级 Tab、模型档位太少、小模型会复读、生图还报「后端启动超时」。

### 2.2 目标

- 生图融入对话流程，不再是一个需要手动点开的弹窗。
- 设置收敛到二级页面，改完统一保存。
- 提供更多轻量模型档位，参数量不要太大。
- 修掉生图不可用的严重缺陷。

### 2.3 范围

| 纳入 | 不纳入 |
|---|---|
| 自动配图、设置页改造、模型扩容、复读保护、生图故障修复 | 多人协作、云同步、模型训练/微调 |

## 3. 功能需求

### 3.1 对话内自动配图（P0）

**描述**：不再展示独立的生图按钮。对话过程中满足以下任一条件时自动生成插图并插入会话：

1. 用户消息里明确要求画图（「画一张…」「来一张…」「draw …」等）。
2. 模型在回复末尾输出了 `<imagine>英文画面描述</imagine>`，表示当前画面值得画出来。

**规则**：
- `<imagine>` 这一行不展示、不保存到聊天记录。
- 自动配图前卸载本地对话模型，避免内存叠加。
- 生图失败只提示，不影响已生成的文字回复。
- 生图模型未下载时不尝试配图，也不向模型注入配图约定。
- 保留「手动生图」入口，放在对话页右上角菜单里，用于临时改提示词。

**验收标准**：
- 说「画一张她在吧台调酒的样子」能在文字回复后自动出现图片。
- 关闭「自动配图」开关后不再触发。

### 3.2 设置改为二级页面（P0）

**描述**：去掉底部「设置」Tab，主页右上角增加菜单键，菜单里进入设置；设置页左上角返回、右上角「保存」。

**规则**：
- 所有编辑先改内存状态，点「保存」才落库；不点保存直接返回则不生效。
- 下载/启停引擎这类动作按页面上当前选中的模型执行，不必先保存。

**验收标准**：改完不保存退出，重新进入设置仍是原值。

### 3.3 模型扩容（P1）

**描述**：对话模型提供更多小参数量档位；生图模型提供更多画风。全部在 App 内下载。

**对话模型**（MNN 格式，taobao-mnn 仓库）：

| 模型 | 体积 | 定位 |
|---|---|---|
| Qwen3 1.7B | 1.2GB | 默认档 |
| Qwen3 0.6B | 450MB | 最轻 |
| Qwen2.5 1.5B | 870MB | 老一代通用 |
| Qwen2.5 0.5B | 280MB | 极小体积 |
| Qwen3 4B | 2.6GB | 质量最好，占内存高 |

**生图模型**（SD1.5，约 1GB/个）：

| 模型 | 画风 |
|---|---|
| Anything V5 | 二次元通用（默认） |
| MeinaMix V12 | 二次元精致 |
| MajicMix Realistic V7 | 写实人像 |
| DreamShaper V8 | 通用插画 |
| Anything V5 CPU | 不支持的机型兜底 |

### 3.4 复读保护（P1）

**描述**：模型连续输出同一行/同一段超过阈值时主动中止本次生成，避免整屏复读。

### 3.6 输出规格与超分（P1，2026-10-30 追加）

**描述**：出图不再是 512 方图，默认为 **4:3 横图**，并做 4x 超分提升清晰度。

**规则**：
- 当前 QNN 模型固定 512×512，实测其它尺寸输出纯噪声，因此比例通过**居中裁切**实现：
  4:3 → 512×384，3:4 → 384×512，1:1 → 512×512。
- 裁切后调用后端 `/upscale` 做 4x 超分，4:3 最终输出 **2048×1536**。
- 超分模型 `realesrgan_x4plus_anime_6b` 约 8MB，App 内下载；未下载或失败时自动降级为裁切原图。
- 设置页「生图输出」提供比例选择、超分开关、超分模型下载与重试。
- 图片统一存 JPEG(q95)，2048×1536 约 680KB。

**验收标准**：
- 默认出图为 4:3、2048×1536，画面清晰无噪声。
- 关闭超分后输出 512×384，不报错。

### 3.5 生图故障修复（P0）

见 `doc/蒋磊/缺陷/BUG-Task02-001.md`：健康检查在主线程发起网络请求导致永远「启动超时」；后端返回原始 RGB 像素被当成 PNG 保存。
