# 项目说明 - Tavern Dream

## 1. 项目概况

| 项 | 值 |
|---|---|
| 项目名称 | Tavern Dream |
| 工程位置 | `/home/elder/IdeaProjects/自用测试/tavern-dream`（2026-10-30 从 `~/Projects` 迁入） |
| 素材目录 | `素材/`：local-dream 原包、MNN 源码（体积大，不入库） |
| 工作区 | `工作区/`：真机截图、日志、临时脚本（不入库，不放 `/tmp`） |
| 项目定位 | 自用 Android 原生角色扮演聊天客户端，内置本地 Stable Diffusion 生图 |
| 参考项目 | [SillyTavern](https://github.com/SillyTavern/SillyTavern)（功能与数据格式参考，AGPL）、[local-dream](https://github.com/xororz/local-dream)（生图内核，CC BY-NC 4.0） |
| 使用范围 | 个人自用，不分发、不商业化 |
| 负责人 | 蒋磊 |
| 创建时间 | 2026-10-29 |

## 2. 项目结构

```
tavern-dream/
├── app/src/main/java/com/taverndream/
│   ├── data/        角色卡、聊天、设置（本地文件存储）
│   ├── llm/         OpenAI 兼容流式对话 + 提示词组装
│   ├── sd/          内置 SD 后端（移植 local-dream）与模型下载
│   └── ui/          Compose 界面（角色列表 / 聊天 / 设置二级页）
├── app/src/main/jniLibs/arm64-v8a/   生图可执行文件（不入库，见 doc/资料）
└── app/src/main/assets/qnnlibs/      QNN 运行库（不入库）
```

## 3. 技术栈

| 项 | 值 |
|---|---|
| 语言 | Kotlin 2.0.21 |
| UI | Jetpack Compose（Material 3） |
| 网络 | OkHttp 4.12（SSE 流式） |
| 序列化 | kotlinx-serialization-json |
| 构建 | AGP 8.7.3 / Gradle 8.14 / JDK 17 |
| compileSdk / minSdk | 34 / 28 |
| ABI | arm64-v8a |

## 4. 开发流程初始化

| 项 | 值 |
|---|---|
| 构建命令 | `gradle assembleDebug`（本机使用缓存的 gradle 8.14，JDK 17） |
| 产物 | `app/build/outputs/apk/debug/app-debug.apk` |
| 生图依赖 | `libstable_diffusion_core.so` + `assets/qnnlibs/*`，从 local-dream 2.4.3 官方 APK 提取 |
| 模型 | 运行时从 HuggingFace（或 hf-mirror）下载，不入库 |
